# Vandana Kumari — Portfolio Website

Responsive static portfolio based on details from the supplied CV.

## Publish with GitHub Pages
1. Sign in to GitHub as `vandanayadav123`.
2. Create a **public** repository named `vandanayadav123.github.io`.
3. Upload the *contents* of this folder to the repository root: `index.html`, `style.css`, `script.js`, `README.md`, and `Vandana-Kumari-CV.docx`.
4. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. After publishing, the expected URL is `https://vandanayadav123.github.io/`.

The website is static and needs no build step. Check your GitHub username and repository settings before publishing. Review the CV and certification date before making the site public. Phone number and passport/visa details are intentionally omitted from the public portfolio.
